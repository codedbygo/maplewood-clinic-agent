## Issues

### ISSUE-010: Evaluation page presented a stale stability result as current (High, functional)
- Repro: open /eval after the 10:55 no-LLM runs. "0 of 40 messages changed across 3 runs" sat beside the free model's results.
- Root cause: `results/stability.json` did not record which model or runs it measured.
- Fix: `eval/stability.py` `build_report` records model, provider, run ids, completeness; `StabilityCard` warns when the model differs, is unrecorded, or a run stopped early.
- Files: eval/stability.py, web/src/features/eval/components/StabilityCard.tsx, EvalPage.tsx, schemas.ts
- Tests: tests/test_stability_regression_qa.py, web/src/features/eval/components/EvalPage.regression-1.test.tsx
- Evidence: screenshots/page-eval.png (before), screenshots/issue-010-after.png. Status: verified.

### ISSUE-009: index.html was cached, so a new build never reached the browser (Medium, functional)
- Repro: rebuild the frontend and reload; the browser kept running `index-hLIUOEEV.js` while `index-BRtNuu62.js` was built.
- Root cause: the SPA route served index.html without Cache-Control, so the browser cached it heuristically, per URL.
- Fix: index.html `Cache-Control: no-cache`; hashed `/assets/*` `max-age=31536000, immutable`.
- Files: console/app.py. Test: tests/test_console_api_regression_qa.py. Status: verified (copies cached before the fix need one reload).

### ISSUE-004: Third-party decline implied the person is a patient (Medium, privacy)
- Repro: "Mike" (not on file) asks about "my wife Grace Park". Reply: "have Grace reach out to us for her schedule details".
- Fix (structural): the post-guard replaces any reply to an unverified sender that names another patient with a fixed neutral decline that names nobody.
- Files: agent/safety.py, agent/runner.py. Tests: tests/test_guard_regression_qa.py. Evidence: issue-004-after.png (the guard fired on a live run). Status: verified.

### ISSUE-002: Reply invented a clinic policy (Medium, content)
- Repro: Spanish booking reply said "avísanos con al menos 24 horas de antelación"; no such policy exists in clinic.json.
- Fix: prompt rule (state only facts from tool results; no invented policies, fees, notice periods); the guard flags policy-like claims for review (does not delete text).
- Files: agent/prompts.py, agent/safety.py. Tests: tests/test_guard_regression_qa.py. Evidence: issue-002-003-after.png. Status: verified on rerun.

### ISSUE-003: Model did date arithmetic instead of using the calendar tool (Medium, functional)
- Repro: "el martes por la mañana" booked without any resolve_date call.
- Fix (structural): the runner finds date phrases in the message and resolves them with the real `resolve_date` tool before the model starts ("the following week" anchored on the previous date; "por la mañana" is not "mañana").
- Files: clinic_mcp/policy/dates.py, agent/runner.py, agent/prompts.py. Tests: tests/test_guard_regression_qa.py. Status: verified (trace shows `resolve_date el martes`).

### ISSUE-007: Schedule page scrolled sideways at phone width (Medium, UX)
- Repro: 390px viewport, /schedule: 502px of content; "Week of Mon, Nov 23" cut off.
- Fix: Segmented control scrolls inside its own box. File: web/src/components/Segmented.tsx. Status: verified (375px in 390px).

### ISSUE-005: Nurse practitioner called "Dr. Kim" (Low, content)
- Fix: the guard corrects titles from the provider list in clinic.json (any provider without "Dr." on file). Tests: test_guard_regression_qa.py. Status: verified ("Sarah Kim, NP").

### ISSUE-006: Markdown in SMS/portal replies (Low, content)
- Fix: the guard converts replies to plain text; prompt says plain text. Status: verified.

### ISSUE-008: Long email overflowed a queue card (Low, visual)
- Fix: `break-words` on the summary. File: QueuesPage.tsx. Status: verified (0 of 26 cards overflow).

### ISSUE-001: Date-of-birth input misaligned with Channel (Low, visual)
- Fix: `sm:items-end` on the form grid (label text unchanged so existing tests stand). Status: verified (both at y=400).
